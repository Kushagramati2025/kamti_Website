# KMATI Website Project

Welcome to the KMATI Website repository. This project is divided into two main parts: a Django backend and an Angular frontend.

## 📂 Project Structure

- **[backend/](./backend/README.md)**: Django REST Framework application handling APIs and database.
- **[frontend/](./frontend/README.md)**: Angular application (v17+) for the user interface.

## 🚀 Getting Started

Please refer to the specific README files in each directory for detailed setup and running instructions.

1.  **Backend Setup**: Go to `backend/` and follow the [Backend README](./backend/README.md).
2.  **Frontend Setup**: Go to `frontend/` and follow the [Frontend README](./frontend/README.md).

## 🛠 Prerequisites Global
- **Node.js**: v18+
- **Python**: v3.10+
- **Git**
